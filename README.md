## 📚 主要学习资源

- **微软官方中文教程**（首选，免费且与 .NET 10 同步更新）
  - C# 入门：https://learn.microsoft.com/zh-cn/dotnet/csharp/tour-of-csharp/
  - ASP.NET Core：https://learn.microsoft.com/zh-cn/aspnet/core/
- **视频补充**：B 站搜索「C# 教程」「ASP.NET Core 教程」，挑播放量高、更新近的系列
- **工具书**（可选）：《C# 入门经典》入门期翻阅即可，不必通读
- **查文档**：https://learn.microsoft.com/zh-cn/dotnet/

## 💡 学习方法（很重要）

1. **以练代看**：视频/文档最多占 30% 时间，剩下 70% 自己敲代码
2. **代码全部传 GitHub**：从阶段 0 就开始，这也是以后找工作的作品集
3. **卡住超过 30 分钟再求助**：先自己查官方文档、搜索，这是必须练的能力
4. **每个阶段必须完成验收标准再进入下一阶段**，宁可慢不可跳
5. **笔记写"坑"**：记录报错和解决过程，比记知识点有用
