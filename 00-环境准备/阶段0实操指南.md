# 阶段 0 实操指南：环境准备

> 按你这台电脑的实际情况写：VS Code / Git / Visual Studio Community 2026 已装好，**只缺 .NET SDK 和 VS 工作负载**。
> 预计总耗时 1~2 小时（大头是下载）。做完一步就去 [进度打卡.md](../进度打卡.md) 勾一项。

## 第 1 步：安装 .NET 10 SDK（约 20 分钟）

打开 PowerShell，运行：

```powershell
winget install Microsoft.DotNet.SDK.10
```

- 会装当前最新版 **10.0.401**（2026-09 安全更新版）
- 不想用命令行：去官网 https://dotnet.microsoft.com/zh-cn/download/dotnet/10.0 下载 **Windows x64 安装器**，双击安装

**装完必须新开一个终端窗口**（旧窗口读不到新 PATH），验证：

```powershell
dotnet --version      # 应显示 10.0.401
dotnet --list-sdks    # 应列出 10.0.401
```

> 你机器上 `C:\Program Files\dotnet` 里已有一个不带 SDK 的旧运行时，装 SDK 会把它补齐，不冲突。

## 第 2 步：给 Visual Studio 2026 补装工作负载（约 30 分钟）

VS 2026 Community 你已装，但里面没有任何 .NET 工作负载，现在补：

1. 开始菜单搜索 **Visual Studio Installer**，打开
2. 找到 **Visual Studio Community 2026** → 点 **修改**
3. 勾选工作负载：
   - ✅ **.NET 桌面开发**（阶段 1~2 的控制台程序用）
   - ❌ ASP.NET 和 Web 开发 → **这次先不勾**，好几个 GB，阶段 4 开始前再补
4. 点右下角 **修改**，等装完

装完打开 VS 2026，登录 Microsoft 账户（Community 版免费但要求登录），选个主题即可。

## 第 3 步：第一个程序 Hello World（10 分钟）

在终端里：

```powershell
cd C:\daybyday\work\code\net10XueXi\01-CSharp基础
dotnet new console -n HelloWorld
cd HelloWorld
dotnet run
```

看到输出 `Hello, World!` 就成功了。

然后用编辑器打开 `Program.cs`，改成下面这样，再 `dotnet run`：

```csharp
Console.WriteLine("你好，.NET 10！");
Console.WriteLine($"今天是 {DateTime.Now:yyyy-MM-dd}");
```

- `$"..."` 叫**字符串插值**：`{}` 里可以放变量或表达式，结果拼进字符串——以后天天用
- 顺便认识三个东西：
  - `Program.cs` —— 你写代码的地方
  - `HelloWorld.csproj` —— 项目配置（目标框架 `net10.0`、依赖的包都声明在这）
  - `bin/`、`obj/` —— 编译产物，**永远不要手动改，也不要提交 Git**（第 5 步的 .gitignore 会排除）

## 第 4 步：用 VS 打开项目 + 断点调试（10 分钟）

1. VS 2026 → **打开项目或解决方案** → 选 `01-CSharp基础\HelloWorld\HelloWorld.csproj`
2. 在 `Console.WriteLine` 那行左侧灰色边条上**点一下**，出现红点 = 断点
3. 按 **F5** 调试运行：程序停在断点上，鼠标悬停在变量上可以看值
4. **F5** 继续执行，**Shift+F5** 停止调试

断点是接下来三个月最常用的排错手段，现在体验一次即可。

## 第 5 步：推送到 GitHub（5 分钟）

Git 你已经会，只列要点。push 前先去 GitHub 网页建一个**空仓库**：New repository → 名字 `net10XueXi` → Public → **不勾选 Add a README**（否则远端多一个提交，第一次 push 会被拒）。

然后在仓库根目录：

```powershell
cd C:\daybyday\work\code\net10XueXi
dotnet new gitignore    # 生成 .NET 专用 .gitignore，自动排除 bin/obj（必须在 git add 之前）
git init -b main        # 这个文件夹还不是 Git 仓库，先初始化，主分支叫 main
git add .
git commit -m "阶段0: 环境搭好，跑通第一个 .NET 10 程序"
git remote add origin git@github.com:你的用户名/net10XueXi.git
git push -u origin main
```

建议仓库同名 `net10XueXi`（公开），整个学习期的代码都放在这一个仓库里。

推完去 GitHub 网页确认两点：能看到 `01-CSharp基础/HelloWorld/Program.cs`；**没有** `bin/`、`obj/` 目录（有就是 .gitignore 没生效，回头检查）。

## 常见问题

- **`dotnet` 不是内部或外部命令** → 没重开终端；还不行就检查 PATH 里有没有 `C:\Program Files\dotnet`
- **winget 找不到包** → 先 `winget source update` 再重试，或直接用官网安装器
- **VS 打开 csproj 提示缺工作负载** → 回第 2 步勾「.NET 桌面开发」
- **push 要求登录/被拒** → 按你熟悉的方式配 SSH key 或 HTTPS token 即可
- **push 被拒（提示 remote contains work you do not have）** → 建仓库时勾了 README：`git pull --rebase origin main` 后再 push
